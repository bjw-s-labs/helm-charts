CiliumNetworkPolicy objects to be generated by the chart. Each key is a policy identifier.

## Type

`object`

## Usage

Keys are identifiers for `ciliumNetworkPolicies` instances.

```yaml
ciliumNetworkPolicies:
  main:
    enabled: true
    # ... configuration

  secondary:
    enabled: true
    # ... configuration
```

### Property Details

#### egress

Cilium egress rules. See https://docs.cilium.io/en/stable/security/policy/language/ for details.

#### egressDeny

Cilium egress deny rules. Deny rules take precedence over allow rules.

#### extraSelectorLabels

Additional match labels to add to the endpoint selector. These are merged with labels derived from the controller identifier.

#### forceRename

Override the default resource name. Mutually exclusive with prefix and suffix.

#### ingress

Cilium ingress rules. See https://docs.cilium.io/en/stable/security/policy/language/ for details.

#### ingressDeny

Cilium ingress deny rules. Deny rules take precedence over allow rules.

#### log

Free-form value included in Hubble flows matching this policy.

#### prefix

Prefix to prepend to the resource name. Mutually exclusive with forceRename.

#### suffix

Suffix to append to the resource name. Defaults to the resource identifier if there are multiple items, otherwise empty. Mutually exclusive with forceRename.
