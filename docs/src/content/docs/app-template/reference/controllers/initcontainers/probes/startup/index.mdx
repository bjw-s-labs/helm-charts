### Property Details

#### custom

Set to `true` to use the raw `spec` object as-is instead of deriving probe details from `type`/`command`/`path`/`port`.

#### service

Identifier of a container port or service to probe. When unset, the probe uses the container&#39;s primary port.

#### type

Probe type. Defaults to `COMMAND` when command is configured, otherwise `TCP`. `AUTO` attempts to infer the probe type from the configured command or the container&#39;s ports.

**Allowed values:** `TCP`, `HTTP`, `HTTPS`, `GRPC`, `COMMAND`, `AUTO`
