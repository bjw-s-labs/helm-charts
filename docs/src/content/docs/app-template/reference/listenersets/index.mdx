Kubernetes Gateway API ListenerSet objects to be generated by the chart. Each key is a ListenerSet identifier. Routes can attach to a ListenerSet by referencing its identifier via the route parentRefs[].identifier key. See https://gateway-api.sigs.k8s.io/references/spec/ for the Gateway API specification.

## Type

`object`

## Usage

Keys are identifiers for `listenerSets` instances.

```yaml
listenerSets:
  main:
    enabled: true
    # ... configuration

  secondary:
    enabled: true
    # ... configuration
```

### Property Details

#### forceRename

Override the default resource name. Mutually exclusive with prefix and suffix.

#### listeners

Listeners associated with this ListenerSet. Each listener defines how the attached Gateway listens for connections.

#### prefix

Prefix to prepend to the resource name. Mutually exclusive with forceRename.

#### suffix

Suffix to append to the resource name. Defaults to the resource identifier if there are multiple items, otherwise empty. Mutually exclusive with forceRename.
