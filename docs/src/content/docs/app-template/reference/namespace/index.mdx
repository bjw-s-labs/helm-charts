Configure the creation of the Helm release namespace.

## Type

`object`

## Properties


| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `annotations` | `object / null` | No | - | Annotations to set on the item. |
| `create` | `boolean` | No | `false` | Set to true to create the Helm release namespace. |
| `labels` | `object / null` | No | - | Labels to set on the item. |
