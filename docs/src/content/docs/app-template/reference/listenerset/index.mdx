Kubernetes Gateway API ListenerSet objects to be generated by the chart. Requires Gateway API &gt;= 1.5.0. See https://gateway-api.sigs.k8s.io/geps/gep-1713/ for the specification.

## Type

`object`

## Usage

Keys are identifiers for `listenerSet` instances.

```yaml
listenerSet:
  main:
    enabled: true
    # ... configuration

  secondary:
    enabled: true
    # ... configuration
```

### Property Details

#### forceRename

Override the default resource name. Mutually exclusive with prefix and suffix.

#### prefix

Prefix to prepend to the resource name. Mutually exclusive with forceRename.

#### suffix

Suffix to append to the resource name. Defaults to the resource identifier if there are multiple items, otherwise empty. Mutually exclusive with forceRename.
