NetworkPolicy objects to be generated by the chart. Omit type for native Kubernetes NetworkPolicies, or set type to cilium for CiliumNetworkPolicies. Supported type values are native and cilium. Additional networkPolicies can be added by adding a dictionary key similar to the &#39;main&#39; networkPolicy.

## Type

`object`

## Usage

Keys are identifiers for `networkpolicies` instances.

```yaml
networkpolicies:
  main:
    enabled: true
    # ... configuration

  secondary:
    enabled: true
    # ... configuration
```

## Examples

```yaml
networkpolicies:
  cilium:
    type: cilium
    endpointSelector:
      matchLabels:
        app.kubernetes.io/name: example
    description: Allow DNS and HTTPS traffic
    ingress:
      - fromEntities:
          - cluster
    ingressDeny:
      - fromEntities:
          - world
    egress:
      - toEntities:
          - cluster
    egressDeny:
      - toEntities:
          - world
    enableDefaultDeny:
      ingress: true
      egress: true
    log: example-policy
```

### Property Details

#### extraSelectorLabels

Additional match labels to add to the pod selector. These are merged with labels derived from the controller identifier.

#### forceRename

Override the default resource name. Mutually exclusive with prefix and suffix.

#### podSelector

Custom podSelector for the NetworkPolicy. Takes precedence over targeting a controller via the controller identifier.

#### prefix

Prefix to prepend to the resource name. Mutually exclusive with forceRename.

#### suffix

Suffix to append to the resource name. Defaults to the resource identifier if there are multiple items, otherwise empty. Mutually exclusive with forceRename.

#### type

Resource implementation to render. Omit this field for a native Kubernetes NetworkPolicy, or set it to cilium for a CiliumNetworkPolicy.

**Allowed values:** `native`, `cilium`
