ExternalSecret objects to be generated by the chart. Each key is an ExternalSecret identifier.

## Type

`object`

## Usage

Keys are identifiers for `externalSecrets` instances.

```yaml
externalSecrets:
  main:
    enabled: true
    # ... configuration

  secondary:
    enabled: true
    # ... configuration
```

### Property Details

#### data

Mappings between Kubernetes Secret keys and provider data. See https://external-secrets.io/latest/api/externalsecret/ for details.

#### dataFrom

Provider data sources whose values are merged into the target Secret. See https://external-secrets.io/latest/api/externalsecret/ for details.

#### forceRename

Override the default resource name. Mutually exclusive with prefix and suffix.

#### prefix

Prefix to prepend to the resource name. Mutually exclusive with forceRename.

#### refreshInterval

Amount of time before values are read again from the SecretStore provider.

#### suffix

Suffix to append to the resource name. Defaults to the resource identifier if there are multiple items, otherwise empty. Mutually exclusive with forceRename.
